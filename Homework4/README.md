## README: Homework 4

This repository contains Python code for simulating a discrete elastic rod subject to external forces, following the specifications outlined in the Homework 4 assignment. The code implements director frames, curvature and twist computation, implicit time-stepping, and visualization of rod dynamics.

### How to Run the Code

1.  **Open the Jupyter Notebook:** Open the `Homework4' notebook in a Jupyter environment.
2.  **Run All Cells:** Execute all the code cells in the notebook sequentially. The notebook is structured to define helper functions first, followed by the main simulation loop and plotting. The simulation will take at around 9 hours to finish.
